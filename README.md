# Boook
Boook is a simple book-reading utility I made. It is written using FTXUI and CPP-PegLib. Special thanks to Xmake.
To install run `brew install rodifed/tap/boook`
To install NVim language server, add this to your lazy setup:
```lua
{
    "rodifed/boook",
    lazy = false,
}
```
